# Step R · Authorize

Decide whether the risk to operations, assets, individuals, other organizations and the
Nation is acceptable and cyberspace operational commanders' requirements are met. The
decision precedes Milestone C and fielding; an AD-IATT covers earlier testing on live
networks (`framework/rmf-steps.yaml`).

## Running the step

- **Run `rmf package` before R-2.** R-1's output is generated: `uv run rmf package <run>`
  writes `package/manifest.yaml`, and `rmf build` refreshes it.
- **Only the AO decides.** The authorization decision (R-4, an `AD-*` decision) cannot be
  delegated; R-2, R-3 and R-5 may be done by the AODR. In a hybrid run, a decision reserved
  for a human with no human answer is a stop condition (`00-run-protocol.md`).
- **The decision is stated once.** `authorizations.yaml` holds the decision; ART-AODM, ART-AUTHRPT
  and later reports cite it by ID instead of restating it.
- **Session unit:** one session for the step.
