# External services

Every service the system relies on but does not own: cloud offerings, enterprise services
(identity, network access points, logging), the cybersecurity service provider and any
software factory. The system description, the leveraged authorizations, the cloud record and
the service agreements cite this file.

## Leveraged services

| Service | Provider | Kind | Authorization | What the system inherits | Agreement |
|---|---|---|---|---|---|
| Example cloud region | Cloud provider | cloud (IaaS, PaaS or SaaS) | FedRAMP or DoD provisional authorization, impact level, date | Controls provided in full or in part | Contract or agreement, date |

Kind is one of: cloud, enterprise service, CSSP, software factory, other organizational
system.

## Cloud responsibilities

For each cloud offering: the service model, the impact level of the mission data, the
customer responsibility matrix (which controls the tenant implements), and the security
technical implementation guides or requirements guides that apply.

## Cybersecurity service provider

Who provides monitoring and incident response, the agreement and its date, and the
evaluation of the provider, if one is on record.
