# Capability document

The capability document (CDD, CPD, capability needs statement, or the user agreement of a
software program) that P-15 derives requirements from. Give its kind, title, version and
approval date, then the parts the security work reads:

## Key performance parameters

Including any cyber survivability or system survivability KPP.

## Operational mode summary and mission profile

How the system is used over time (OMS/MP), if the document has one. Without it, P-15 uses
`conops.md` and records an assumption.

## Protection content

What the document says about program protection, cybersecurity and supply chain.
